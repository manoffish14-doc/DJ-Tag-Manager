Genre Cleanup vertical family layout
- Main genres in side-by-side vertical columns, with related subgenres below and counts.
- Main genre heading selects/deselects every subgenre in that family; individual rows can be toggled.
- Seven built-in families remain visible even when empty. Add custom families and subgenres.
- Save Changes writes immediately, without preview or confirmation. Genre becomes parent; Composer is overwritten with the original subgenre.
- Uses metadata_safety.safe_write for recovery backups and records genre_cleanup_written history.
- Changes are limited to v3.1. Live macOS GUI and file-writing behavior still require verification.
